# v0.1.0 使用与页面采集

## 首版状态

这是一版可运行的中文工程基础及页面采集工具，**尚不能直接在英盛自动跑课**。自动队列代码已经提供，但必须先确认你登录后的页面，不能把模板的verified改成true就算完成适配。

## Windows 11

1. 从本仓库Release下载Windows x64 ZIP，解压运行EXE；本机需已安装Edge，无需Python。
2. 点“打开课程中心 / 登录”，在打开的专用Edge窗口人工登录。不要把账号密码发给开发者。
3. 进入“英盛页面适配”选项卡。每次采集前点“刷新标签页”，选择当前所在的标签页。
4. 分别在课程中心、课程详情/章节列表、具体播放器页面点对应采集按钮。新开标签页时重新刷新选择。
5. 点“打开本机资料目录”，在reports文件夹检查三份JSON。可配合三张截图说明课程进度和分页；截图请遮住姓名、工号等。
6. 只分享检查过的reports文件；绝不分享edge-profile文件夹、Cookie或完整浏览器资料。助手不会自动上传任何报告。

若JSON未包含状态文字，请补充状态位置截图；原始采集不读取整页HTML、输入值、网络请求或存储。它可能需要下一版有针对性采集，不会盲目扩大采集范围。

## 核实适配以后

导入经过确认的配置；只留一个课程中心标签页，点“自动处理未完成课程”。按平台显示状态扫描、跳过已完成课时并正常播放。播放结束回到列表确认，状态不明确即停。暂停/继续用于用户主动操作；“需要人工处理”后，应先解决浏览器提示，再重新启动队列，由平台列表决定续播，而不是读取本地记录直接跳过。

电脑睡眠或浏览器关闭会中止流程。首版不改变Windows电源策略，也不保证无人值守时获得学分。程序界面的“本机观察时长”不能当作平台课时。

## 数据与错误

本机目录：`%LOCALAPPDATA%\CourseAutoAssistant`。支持清除助手登录，不改变日常Edge。打开浏览器失败时检查Edge安装、网络、企业浏览器策略、其他助手实例。不要关闭企业安全策略。EXE未签名，如系统拦截，请核实来源、校验值并联系设备管理员，不建议关闭安全软件。
