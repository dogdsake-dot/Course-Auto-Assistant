# 本机数据与隐私

- 浏览器Cookie、localStorage等由专用Edge用户目录保存，不导出为共享配置，不提交GitHub，不包含在Release。它们是敏感登录资料，并不等于助手额外加密的保险箱。
- 默认位置 `%LOCALAPPDATA%\CourseAutoAssistant\edge-profile`。只在自己的受信任Windows账号运行。退出会关闭助手的浏览器并保留本机状态；“清除本机登录”会删除整个专用资料目录。
- 程序不要求用户在界面填写账号密码，不访问日常Edge资料，不上传遥测、不自动把截图或网页发到GitHub。
- 用户主动采集的报告包含标签页路径、部分元素ID/class、按钮/链接文字和父节点结构。查询参数、片段和URL中的账号密码被移除，常见邮箱/手机号做掩码；**这不是完整匿名化保证**，路径和文字仍可能含课程/企业信息，必须人工检查后分享。
- 不采集输入框值、Cookie、网络头、网络请求体、完整HTML、浏览器存储或媒体下载地址。
- 本地last-run.json保存最近一轮的课时名和观察状态，只用于记录；不是重放请求或申报完成的依据。
- 仓库gitignore列出常见资料目录。不要在公开issue里粘贴登录信息；gitignore也不能撤回曾经已提交的秘密。
